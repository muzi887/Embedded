# GenerateProgressBar1 函数功能说明

## 函数原型

```c
void GenerateProgressBar1(u8 curr, u8 all, u8 *segment)
```

## 功能概述

在 LCD12864 屏幕上绘制一条进度条线段。将 128 像素宽的线段平均分成 `all` 份，并点亮第 `curr` 份对应的区域，其余区域熄灭。

## 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `curr` | `u8` | 当前要显示的是第几份，范围 **1 ~ all** |
| `all` | `u8` | 将线段分割的总份数，范围 **1 ~ N** |
| `segment` | `u8*` | 输出缓冲区，需 **16 字节**（8段 × 2字节/段） |

## 内部计算逻辑

### 1. 参数校验

- `all == 0` → 修正为 1（防止除零）
- `curr == 0` → 修正为 1（最小值为 1）
- `curr > all` → 修正为 `all`（不超过总份数）

### 2. start / end 计算

函数内部根据 `curr` 和 `all` 自动计算像素起止位置（0~127）：

```
start = (curr - 1) * 128 / all
end   = curr * 128 / all - 1    （当 curr < all 时）
end   = 127                      （当 curr == all 时，确保覆盖到末尾）
```

**示例**（`all = 4`，即分成 4 份）：

| curr | start | end | 点亮像素范围 |
|------|-------|-----|-------------|
| 1 | 0 | 31 | 第 0~31 像素 |
| 2 | 32 | 63 | 第 32~63 像素 |
| 3 | 64 | 95 | 第 64~95 像素 |
| 4 | 96 | 127 | 第 96~127 像素 |

**示例**（`all = 11`，即分成 11 份）：

| curr | start | end | 点亮像素范围 |
|------|-------|-----|-------------|
| 1 | 0 | 10 | 第 0~10 像素 |
| 2 | 11 | 22 | 第 11~22 像素 |
| ... | ... | ... | ... |
| 11 | 116 | 127 | 第 116~127 像素 |

## 数据格式

### 线段分段结构

128 个像素点分为 **8 段**，每段 16 个像素点，每段用 **2 个字节** 表示：

```
段0        段1        段2        ...  段7
[B0][B1]  [B2][B3]  [B4][B5]   ... [B14][B15]
像素0~15  像素16~31  像素32~47  ... 像素112~127
```

### 字节内位序：高位在右、低位在左

每段的 2 个字节中：
- `segment[n*2]` — **低字节**，对应该段的像素位置 0~7
- `segment[n*2+1]` — **高字节**，对应该段的像素位置 8~15

位映射规则（以低字节为例）：

```
bit7  bit6  bit5  bit4  bit3  bit2  bit1  bit0
 ←───────────────────────────────────────────→
pos0  pos1  pos2  pos3  pos4  pos5  pos6  pos7
```

即 MSB（bit7）对应该字节组中最左侧的像素，LSB（bit0）对应最右侧的像素。

### 填充示例

以 `curr=1, all=4`（点亮像素 0~31）为例：

```
段0: segment[0] = 0xFF, segment[1] = 0xFF   → 像素 0~15 全亮
段1: segment[2] = 0xFF, segment[3] = 0xFF   → 像素 16~31 全亮
段2: segment[4] = 0x00, segment[5] = 0x00   → 像素 32~47 全灭
段3: segment[6] = 0x00, segment[7] = 0x00   → 像素 48~63 全灭
...
段7: segment[14]= 0x00, segment[15]= 0x00   → 像素 112~127 全灭
```

## LCD 写入

函数在计算完 segment 数据后，自动写入 LCD12864 的 GDRAM：

1. 进入扩展指令集（`0x34`）并打开绘图显示（`0x36`）
2. 设置 Y 坐标（行地址）为 `0x80 + 14`（第 14 行）
3. 设置 X 坐标（列地址）为 `0x80`（从第一列开始）
4. 依次写入 8 段共 16 字节数据

```
LCD GDRAM 第14行:
[seg0-Lo][seg0-Hi][seg1-Lo][seg1-Hi] ... [seg7-Lo][seg7-Hi]
  0x80     0x81     0x82     0x83          0x87     0x87
```

## 处理流程图

```
GenerateProgressBar1(curr, all, segment)
│
├─ 参数校验（all≠0, 1≤curr≤all）
│
├─ 计算 start, end
│   start = (curr-1)*128/all
│   end = curr*128/all - 1  （末份end=127）
│
├─ memset(segment, 0, 16)   ← 全部清零
│
├─ 判断 startSegment == endSegment ?
│   ├─ 是 → 同一段内部分填充
│   │   ├─ fillCount ≤ 8 → 只填低字节
│   │   └─ fillCount > 8 → 填低字节+高字节
│   │
│   └─ 否 → 跨段填充
│       ├─ 起始段：部分填充（低字节或高字节）
│       ├─ 中间段：全部置 0xFF
│       └─ 结束段：部分填充（低字节或高字节）
│
└─ 写入 LCD GDRAM（第14行）
```

## 调用示例

```c
u8 xianshi[16];  // 16字节缓冲区

// 将线段分成11份，显示第1份
GenerateProgressBar1(1, 11, xianshi);

// 将线段分成4份，显示第3份
GenerateProgressBar1(3, 4, xianshi);

// 将线段不分割，显示全部（1份中的第1份 = 全亮）
GenerateProgressBar1(1, 1, xianshi);
```

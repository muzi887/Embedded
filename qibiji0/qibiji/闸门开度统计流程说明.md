# 闸门开度统计流程说明

## 一、相关模块与数据流概览

```
                    ┌─────────────────────────────────────────────────────────┐
                    │                    TIM2 中断 (5ms)                       │
                    │  JudeCount() → ChangeReality()  每 5ms                   │
                    │  JudeDir()    限位判断           每 5ms                   │
                    │  JudeKaidu()  开度固化           每 500ms                 │
                    └────────────────────────┬────────────────────────────────┘
                                             │
    光电编码器 CODE1/CODE2 ──脉冲──→  Num_count (转数/脉冲计数)
                                             │
                                             ▼
                    ┌─────────────────────────────────────────────────────────┐
                    │  ChangeReality()  (switch.c)                             │
                    │  kaival = Num_count * 100 / gate_maxturns                     │
                    │  armReg.range_reality = kaival                           │
                    └────────────────────────┬────────────────────────────────┘
                                             │
                                             ▼
                    ┌─────────────────────────────────────────────────────────┐
                    │  JudeKaidu()  (switch.c)  电机停止且 Num_count 稳定后     │
                    │  armReg.gate_kaidu = kaival  → 写入 EEPROM               │
                    └────────────────────────┬────────────────────────────────┘
                                             │
                                             ▼
                    ┌─────────────────────────────────────────────────────────┐
                    │  dc_motor.c  (dcmotor_ctrl)                             │
                    │  t3: 上升到达目标  range_reality >= range_target         │
                    │  t4: 下降到达目标  range_reality <= range_target         │
                    └─────────────────────────────────────────────────────────┘
```

---

## 二、核心变量说明

| 变量 | 类型 | 含义 | 单位/范围 |
|------|------|------|-----------|
| **Num_count** | u16 | 转数/脉冲计数，由光电编码器累积 | 0 ~ gate_maxturns |

| **armReg.gate_maxturns** | u16 | 全开时的总转数（满量程脉冲数） | 由自动校准或 EEPROM 保存 |
| **armReg.gate_kaidu** | u16 | 闸门开度（固化值） | 0~100 百分比 |
| **armReg.range_reality** | u16 | 实时开度 | 0~100 百分比 |
| **armReg.range_target** | u16 | 目标开度（远程控制用） | 0~100 百分比 |
| **kaival** | u8 | 临时开度百分比 | 0~100 |

---

## 三、详细流程

### 3.1 脉冲计数 (JudeCount → ChangeReality)

**位置**：`switch.c`，由 TIM2 每 5ms 调用 `JudeCount()`。

- CODE1 (PB4)、CODE2 (PB0) 为光电编码器，低电平有效
- 检测到有效边沿时调用 `ChangeReality()`
- **上升**：`Num_count++`（不超过 gate_maxturns）
- **下降**：`Num_count--`（不低于 0）

### 3.2 开度计算 (ChangeReality)

```c
kaival = Num_count * 100 / armReg.gate_maxturns;
armReg.range_reality = kaival;
```

- 开度 = 当前脉冲数 / 全开脉冲数 × 100
- 每次脉冲变化都会更新 `kaival` 和 `range_reality`

### 3.3 限位处理 (JudeDir)

- **上限位**：`FLAG_OPENALL=1`，`Num_count` 保持为 gate_maxturns（若 autoFlag 则更新 gate_maxturns）
- **下限位**：`FLAG_CLOSEALL=1`，`Num_count=0`

### 3.4 开度固化 (JudeKaidu)

**位置**：`switch.c`，TIM2 每 500ms 调用。

- 条件：电机停止且 `changeFlag==1`
- 若连续两次（500ms 间隔）`Num_count` 不变，则 `armReg.gate_kaidu = kaival`，并写入 EEPROM

### 3.5 电机控制 (dc_motor.c)

- **t3**：上升时 `range_reality >= range_target` 且 `remoteflag` → 停止
- **t4**：下降时 `range_reality <= range_target` 且 `range_target != 0` 且 `remoteflag` → 停止
- **t1/t2**：到达限位 → 停止

## 四、逻辑漏洞

### 4.1 【严重】Num_count 初始化单位错误

**位置**：`reg.c` 第 56 行

```c
Num_count = armReg.range_reality;  // range_reality = gate_kaidu (0~100)
```

**问题**：`Num_count` 应为脉冲数（0 ~ gate_maxturns），却被赋成 `gate_kaidu`（0~100 百分比）。

**后果**：若 gate_kaidu=50、gate_maxturns=80，则 Num_count=50。此时 kaival=50×100/80=62，与真实 50% 不符；且 Num_count 会与 gate_maxturns 比较，逻辑混乱。

**正确写法**：

```c
Num_count = (u16)((u32)armReg.gate_kaidu * armReg.gate_maxturns / 100);
```

---

### 4.2 【严重】ChangeReality 中 FLAG 判断错误

**位置**：`switch.c` 第 108 行

```c
if (sys_moter_state == MOTOR_UP && !FLAG_CLOSEALL && !FLAG_CLOSEALL)  // 重复
```

**问题**：应为 `!FLAG_OPENALL`，误写成 `!FLAG_CLOSEALL` 重复。

**后果**：上升时未正确判断是否已到上限位，可能导致 Num_count 超过 gate_maxturns 或逻辑异常。

**正确写法**：

```c
if (sys_moter_state == MOTOR_UP && !FLAG_OPENALL && !FLAG_CLOSEALL)
```

---

### 4.3 【中等】gate_maxturns 为 0 时除零

**位置**：`switch.c` 第 123 行

```c
kaival = Num_count * 100 / armReg.gate_maxturns;
```

**问题**：gate_maxturns 为 0 时除零，未定义行为。

**建议**：增加保护：

```c
if (armReg.gate_maxturns > 0)
    kaival = Num_count * 100 / armReg.gate_maxturns;
else
    kaival = 0;
```

---

### 4.4 【中等】远程目标为 0 时无法通过 t4 停止

**位置**：`dc_motor.c` 第 261 行

```c
t4 = sys_moter_state == MOTOR_DOWN && armReg.range_reality <= armReg.range_target 
     && armReg.range_target != 0 && remoteflag;
```

**问题**：`range_target != 0` 导致目标为 0（全关）时 t4 永远为假。

**后果**：远程下发“全关”时，只能靠 t1（下限位）停止；若下限位故障，电机无法在 0 处停止。

**建议**：去掉 `range_target != 0`，或改为：`(range_target == 0 && range_reality == 0) || (range_target != 0 && range_reality <= range_target)`。

---

### 4.5 【中等】armReg.range_target 未初始化

**位置**：`reg.c`、`initReg()`

**问题**：`range_target` 未在 `initReg()` 或 `eepromToPara()` 中赋值，默认可能为 0 或随机值。

**后果**：远程控制前若未下发目标，可能导致误判到达目标。

**建议**：在 `eepromToPara()` 或 `initReg()` 中赋初值，如 `armReg.range_target = armReg.gate_kaidu`。

---

### 4.6 【低】JudeKaidu 稳定判定依赖 500ms 周期

**位置**：`switch.c` JudeKaidu()

**问题**：需连续两次 500ms 内 Num_count 不变才写入 gate_kaidu。若主循环或定时器异常，可能长期不写入。

**建议**：可增加超时逻辑，或缩短判定周期。

---

### 4.7 【低】autoFlag 时 gate_maxturns 被覆盖

**位置**：`switch.c` JudeDir() 第 196 行

```c
if (autoFlag)
{
    armReg.gate_maxturns = Num_count;
    ...
}
```

**问题**：自动校准时用当前 Num_count 覆盖 gate_maxturns。若此时 Num_count 异常（误计数、未到顶等），会破坏 gate_maxturns。

**建议**：增加合理性检查，如 Num_count 需大于某阈值才更新。

---

## 五、修复建议汇总

| 优先级 | 漏洞 | 建议修改 |
|--------|------|----------|
| P0 | Num_count 初始化 | `Num_count = gate_kaidu * gate_maxturns / 100` |
| P0 | FLAG_CLOSEALL 重复 | 改为 `!FLAG_OPENALL` |
| P1 | gate_maxturns 除零 | 增加 `gate_maxturns > 0` 判断 |
| P1 | range_target==0 无法停止 | 调整 t4 条件 |
| P2 | range_target 未初始化 | 在 initReg/eepromToPara 中赋值 |
| P2 | gate_maxturns 覆盖无校验 | 增加合理性检查 |

## 六、数据流时序图

```
上电/复位
    │
    ▼
para_read() → eepromToPara()
    │
    ├─ Num_count = range_reality  ← 【漏洞】应为 gate_kaidu*gate_maxturns/100
    └─ kaival = gate_kaidu

电机运行中 (TIM2 每 5ms)
    │
    ├─ JudeCount() → CODE1/CODE2 脉冲 → ChangeReality()
    │       ├─ 上升: Num_count++
    │       ├─ 下降: Num_count--
    │       └─ kaival = Num_count*100/gate_maxturns
    │
    └─ JudeDir() → 限位 → FLAG_OPENALL/FLAG_CLOSEALL, Num_count 归位

电机停止后 (TIM2 每 500ms)
    │
    └─ JudeKaidu() → Num_count 稳定? → gate_kaidu=kaival → EEPROM

远程控制 (gprs_rx cjson_setting)
    │
    └─ range_target = rxparagate
    └─ dcmotor_ctrl t3/t4 判断 range_reality 与 range_target
```

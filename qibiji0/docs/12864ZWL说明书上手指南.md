# 如何用《12864ZWL 说明书》学会在开发板上点亮液晶

目标：把 `ZIKU/12864ZWL模块说明书_V2 (支持3.3~5.0V宽压)(1).pdf` 读成**能动手改屏**的知识，并对照本仓库已有驱动在开发板上验证。

说明书路径：

- `ZIKU/12864ZWL模块说明书_V2 (支持3.3~5.0V宽压)(1).pdf`
- 字模工具：`ZIKU/PCtoLCD2002完美版/`（取点阵用）
- 工程驱动：`qibiji/HARDWARE/Lcd12864/`（本板已接好的代码）

更偏业务页面的梳理见：`qibiji/LCD显示流程梳理.md`。本文只讲**如何读说明书 + 如何在本板上练手**。

---

## 0. 先搞清：说明书和工程各解决什么

| 材料 | 作用 |
|------|------|
| PDF 说明书 | 告诉你屏的引脚、串/并口时序、指令、DDRAM/GDRAM 地址、例程写法 |
| 本工程 `Lcd12864.*` | 已经按**串口模式**写好底层收发，你不必从零写 bit-bang |
| `Dispaly.c` | 业务页面（首页/设置/4G…），调用底层 `ShowQQCharH` 等 |
| `PCtoLCD2002` | 把汉字/图标变成点阵数组（画图用）；汉字文本显示多数直接写 **GB2312 内码** |

学习原则：**说明书看原理，工程看落地。** 不要一上来背完整指令表，按下面「五天路径」对照做。

## 1. 本开发板实际怎么接的（对照说明书第三章）

说明书第三章把脚分成「未固定 / 固定并口 / 固定串口」三种定义。本工程走的是**串口（3 线）模式**：

| 屏脚（说明书串口名） | 工程宏 | STM32 引脚 |
|----------------------|--------|------------|
| CS（片选，高有效） | `CS` | PE3 |
| SID（串行数据） | `SID` | PE4 |
| SCLK（串行时钟） | `SCLK` | PE5 |
| 背光 BLA/BLK 相关 | `BackLight` | PA0 |
| PSB | 串口模式应选串口（PCB 上常短接 “S”，或拉低） | 板级已定，代码里未再控 PSB |

头文件注释也写了：液晶驱动侧常按 5V 逻辑，STM32 要用 **5V 兼容 IO**。

电压注意（说明书第一章）：

- 模块支持 **3.3～5.0V 宽压**
- **3.3V 供电时**，背光相关脚若偏暗，需按说明书把焊盘接到 **“3V”** 实测点（说明书封面图有说明）

读 PDF 时重点看：

- **第三章第三节「串口时管脚说明」** — 和本板一致
- **第八章第三节「接口串口应用原理图」** — 理解只接 CS/SID/SCLK 为何够用

并口章节（八位/四位）可浏览，本板**不用**。

## 3. 说明书章节 → 你该学到什么 → 工程哪里对应

### 3.1 第五章：显示结构（最重要）

**DDRAM（文字层）**

- 一屏静态大约 **4 行 × 8 个汉字**（一行最多 8 个汉字位；半宽字符可塞更多）
- 每个汉字占一个 DDRAM「格」，写入 **2 字节 GB2312 内码**（高字节在前）
- 四行常用起始地址（说明书与例程一致）：

| 行 | DDRAM 起始 | 本工程常见用法 |
|----|------------|----------------|
| 第 1 行 | `0x80` | 标题/时间等 |
| 第 2 行 | `0x90` | 如开度、信号 |
| 第 3 行 | `0x88` | 如电机、CCID |
| 第 4 行 | `0x98` | 如流量、状态 |

工程示例（首页）：

```c
ShowQQCharH(0x90, kaidu, 8);   // 第2行
ShowQQCharH(0x88, motor, 8);   // 第3行
ShowQQCharH(0x98, liuliang, 8);// 第4行
```

字符串内容是 **GB2312 字节数组**，不是 UTF-8。例如 `"开度"` 在源码里是 `0xbf,0xaa,0xb6,0xc8`。

**GDRAM（绘图层）**

- 按「先写垂直地址、再写水平地址」写入，地址都要加 `0x80`
- 扩展指令打开绘图：`0x34` → `0x36`（见工程 `WRGDRAM*` / `CLEARGDRAMH`）
- 用于进度条、边框、小图标；与文字可叠加显示

读 PDF 时对着第五章的映射图，在纸上标：`0x80/90/88/98` 各在屏幕哪一行。

### 3.2 第六章：串口时序（理解即可，不必手抄）

串口模式下，一次写命令/数据大致是：

1. 起始同步字节（工程里 `0xF8` 或 `0xFA`，由 RS 决定）
2. 高 4 位放在一个字节的高半部发出
3. 低 4 位再发一个字节  

对应工程：

```c
SPIWH() → SendByteLCDH(0xf8 + (WRS<<1));
        → SendByteLCDH(Wdata & 0xf0);
        → SendByteLCDH((Wdata << 4) & 0xf0);
```

说明书时序图用来核对：**SCLK 边沿、CS 何时拉高**。若自己移植到新板，时序错了会花屏/无显示。

### 3.3 第七章：指令（先背这几个）

| 指令/操作 | 含义 | 工程位置 |
|-----------|------|----------|
| `0x30` | 基本指令集、8 位接口 | `LCDInit` / `ShowQQCharH` 开头 |
| `0x0C` | 开显示、关光标 | `LCDInit` |
| `0x06` | 地址递增 | `LCDInit` |
| `0x02` | 地址归位 | `LCDInit` |
| `0x01` | 清 DDRAM（空白） | 例程有，业务页偶尔用 |
| 写地址再写数据 | 设 DDRAM 后写内码 | `ShowQQCharH` |
| `0x34` / `0x36` | 扩展指令 + 开绘图 | `CLEARGDRAMH` 等 |

其余扩展指令（反白、睡眠、卷动）用到再查 PDF 第七、三节。

### 3.4 第九章：例程 ≈ 本仓库驱动原型

说明书第九章的函数名与本工程高度同构：

| 说明书例程 | 本工程 |
|------------|--------|
| `WRCommandH` / `WRDataH` / `SPIWH` / `SendByteLCDH` | `Lcd12864.C` 同名 |
| `LCDInit` | `Dispaly.c` |
| `ShowQQCharH` | 显示汉字串 |
| `ShowNUMCharH` | 半宽数字/符号 |
| `WRCGRAMH` / `ShowCGCharH` | 自定义字符 |
| `WRGDRAM128X8` / `CLEARGDRAMH` | 绘图区 |

因此：**读第九章例程注释 = 读本工程底层注释。** 差别主要在 GPIO 宏从 51 单片机的 `sbit` 换成了 STM32 的 `PEout(n)`。

## 4. 动手学习路径（建议按天做）

### Day 1：确认硬件与点亮

1. 对照说明书第三章串口脚，用万用表确认 PE3/4/5、电源、背光。
2. 编译下载现有工程，主循环里已有 `Lcd_Process()`，应能看到业务首页。
3. 按键应能点亮背光（`BLight_Ctrl`：有键开背光，久无关闭）。

若无显示：先查供电/宽压焊盘、PSB 是否为串口、CS/SID/SCLK 是否接反——这些在说明书第三、四、八章。

### Day 2：改一行字（DDRAM）

目标：理解「地址 + GB2312」。

1. 在 `homepage()` 里临时改 `ShowQQCharH` 的地址或字符串数组。
2. 用说明书第五章核对：改 `0x80` / `0x90` / `0x88` / `0x98` 时字出现在哪一行。
3. 汉字编码：可用「内码提取」工具（`ZIKU` 目录下的 exe），或查表得到两字节写入数组。

最小实验思路（理解即可）：

```c
// 第1行显示固定内容（count=汉字个数，每字2字节）
uint8_t hello[4] = {0xC4, 0xE3, 0xBA, 0xC3}; // 「你好」GB2312
ShowQQCharH(0x80, hello, 2);
```

### Day 3：跟一遍初始化与写命令

打开说明书第九章第五节 + 工程 `LCDInit` / `WRCommandH`：

1. 上电延时为何要约 1～1.5s（`Lcd_Init` 里 `delay_ms(1500)`）。
2. `0x30 → 0x06 → 0x0C → 0x02` 各自作用（对照第七章）。
3. 用示波器或逻辑分析仪看 SCLK/SID（可选）：验证与第六章时序一致。

### Day 4：画一条线 / 清屏（GDRAM）

1. 读说明书第五章 GDRAM 分布 + 第九章 `CLEARGDRAMH` / `WRGDRAM128X8`。
2. 在测试页调用 `CLEARGDRAMH(0x00)` 清图，再 `WRGDRAM_line()` 或工程里现成的 `WRGDRAM` 画图标。
3. 搞清：**文字走 DDRAM，点阵图画走 GDRAM**，两者可同时开。

### Day 5：字模工具（图标/特殊字形）

当内置字库没有你要的符号，或要画 logo：

1. 打开 `ZIKU/PCtoLCD2002完美版/PCtoLCD2002.exe`。
2. 按说明书「横向取模」等要求选模式（与 `code[][24]` 一类数组匹配；工程里图标多为 12×12 / 16×16 横向数据）。
3. 生成 C 数组，粘到工程，用 `WRGDRAM` / 自定义 CGRAM 显示。

文字业务界面优先用 **内码 + `ShowQQCharH`**，不必每个字都取模。

## 5. 工程里「从 main 到屏幕」最短调用链

```
main()
  Lcd_Init()              // GPIO + 清 GDRAM + homepage
  while(1)
    Lcd_Process()
      BLight_Ctrl()       // 背光
      LcdDisplay()        // 事件驱动刷新页面
        homepage()/setpage()/...
          LCDInit()
          ShowQQCharH(...) / WRGDRAM(...)
            WRCommandH / WRDataH
              SPIWH → SendByteLCDH → CS/SID/SCLK
```

分层记忆：

1. **引脚电平** = 说明书第六章时序  
2. **命令/数据** = 说明书第七章  
3. **写哪一行字** = 说明书第五章 DDRAM 地址  
4. **业务刷什么** = `Dispaly.c` 各 page

## 7. 常见坑（说明书 + 本板）

| 现象 | 优先排查 |
|------|----------|
| 全黑/全白无字 | 供电、对比度 VO、初始化是否执行、`LCDInit` 是否被调用 |
| 乱码 | 当 UTF-8 写了；或半宽/全宽混用错位 |
| 字跑到奇怪位置 | DDRAM 地址用错（第三行是 `0x88` 不是 `0xA0`） |
| 只有字没有图 / 反过来 | 扩展指令 `0x34/0x36` 与基本集 `0x30` 切换顺序错 |
| 花屏、偶发错字 | 写命令后延时不够（说明书串口延时；工程 `delay_us`） |
| 3.3V 背光暗 | 宽压焊盘接「3V」（说明书第一章） |

## 9. 下一步练什么

1. 新建一个「测试页」：只显示固定四行文字，不跑业务逻辑。

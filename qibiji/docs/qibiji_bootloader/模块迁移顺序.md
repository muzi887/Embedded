# qibiji_bootloader 模块迁移顺序

> 目标：从 `qibiji_boot` 向 `qibiji_bootloader` 逐模块迁移，**每个阶段结束时工程都可编译、可单独验证**，
> 依赖只指向已入库的模块。高耦合的 BOOT 与 main 状态机放到最后。

## 1. 依赖关系（谁用谁）

| 模块 | 依赖 |
|---|---|
| STMFLASH | 无（固件库） |
| IIC / 24CXX | IIC←delay；24CXX←IIC |
| REG | 24CXX；OTA_InfoCB 结构体定义（随 REG 入库迁到 reg.h） |
| WDG / LED / CRC16 / cJSON | 无（叶子） |
| 4G | 无（EXTI 电平） |
| Lcd12864（含 display.h 错误码） | 无 |
| USART（usart1 调试口 + usart2 DMA 环形缓冲） | 无 |
| GPRS（tx/frame/session/rx） | USART2、4G、REG（OTA_Info + MQTT 键）、STMFLASH（写 A2 + 分区地址）、CRC16、cJSON、（进度条用 LCD） |
| BOOT（boot.c + ota_copy.c） | STMFLASH（读写 + 分区地址）、REG（标志读写 + OTA_Info）、Lcd12864（OTA_ERR_*）、USART（printf） |
| main.c 状态机 | 全部 |

## 2. 迁移顺序（12 个阶段，每阶段可编译可验证）

| # | 阶段 | 内容 | 单独验证方法 |
|---|---|---|---|
| 1 | 工程骨架 | CORE + FWLib + SYSTEM(sys/delay) + 最小 main | 编译通过，delay 空转/LED 闪烁 |
| 2 | USART | usart1（printf 重定向）+ usart2（DMA 环形缓冲） | printf 输出；usart2 回环/透传收发 |
| 3 | WDG | IWDG 初始化 + 喂狗 | 开狗后喂狗正常运行；注释喂狗验证复位 |
| 4 | STMFLASH + 分区布局 | Flash 读/写/擦；分区宏（B/A1/A2 地址 + 编译期断言）落在 `stmflash.h` 或独立 `flash_layout.h` | 在 A2 区地址试写一页并回读比对（不碰 B/A1） |
| 5 | IIC + 24CXX | GPIO 模拟 I²C + AT24C02 字节/定长读写 + Check 播种 | 写读字节/字比对；Marker 播种判定 |
| 6 | REG | 参数登记处：**OTA_InfoCB/偏移/布局断言从 boot.h 迁到 reg.h**；五个 OTA 标志函数在此新建（不再从 boot.c「迁入」）；MQTT 键读写 | 写 OTA_flag/UPDATE_flag → 断电回读；MQTT 键读出 |
| 7 | LED + 4G + 其它独立小驱动 | LED；4G 在线电平 EXTI（gprsonlineflag）；DS1302 等按需 | 电平读数、中断触发计数 |
| 8 | Lcd12864 | LCD 驱动 + display.h（**OTA_ERR_* 错误码在此定义**） | 画点/字符串/进度条 |
| 9 | CRC16 + cJSON | 纯算法叶子 | 已知向量单测（CRC 对标准帧算一遍） |
| 10 | GPRS | gprs.h（返回码改 OTA_RX_*）+ gprs_tx + gprs_frame + gprs_session + gprs_rx | 连上 MQTT；putVersion 往返；假固件包下载写 A2 并回读 |
| 11 | BOOT | boot.c + ota_copy.c（按《BOOT模块重构.md》修订版落盘） | 手工往 A2 塞一份合法镜像 → 上电搬运 → 校验 → 跳 A1；再测坏镜像被护栏拦截 |
| 12 | main + 整机联调 | 正式 OTA 状态机 main.c；替换各阶段的临时验证代码 | 端到端 OTA：平台下发 → 下载 → 搬运 → 新版本运行 |

各阶段临时 main 的用法：USER/main.c 先写成**当前阶段的验证代码**（如阶段 5 就是「写 EEPROM→回读→printf」），
下一段迁移时替换掉。正式状态机到阶段 12 才写。

## 3. 对《BOOT模块重构.md》的连带修订（到阶段 11 执行）

1. `OTA_InfoCB` 结构体、字段偏移、`OTA_ADDR`、`OTA_RETRY_*`、布局断言 → **迁出 boot.h，归 reg.h**（REG 是 24C02 布局的属主，阶段 6 先落地）；
2. 分区宏（`ST32_B/A1/A2_*`、分区编译期断言）→ **迁到阶段 4 的 Flash 布局头**（GPRS 写 A2 也要用，不能锁在 boot.h 里）；
3. boot.h 只留 BOOT 自己的东西：入口类型、`OtaCopyPlan_CB`、LCD 错误登记、函数声明；
4. 附录 1「REG 联动」作废——五个标志函数改为阶段 6 在 reg.c **直接新建**（代码文本不变，注释按当前规范写）；
5. include 调整：boot.c 不再 include boot.h 里的 EEPROM 头；`24cxx.h`（EE_ADDR 断言）随断言一起搬到 reg.h / 布局头。

## 4. 工程文件约定

每阶段新增的 .c/.h 由你在 Keil 里手动加入 `qibiji_bootloader.uvprojx` 对应分组（我此前承诺不动工程文件；
若要我代改，届时说一声即可）。编译不过的模块不入库，验证通过才进下一阶段。

> **引脚/EXTI 配置逐行等价；行为修订三处**（热重启保护、ISR 简化、复位脉冲后喂狗）——均源自 zxl 重写版，

> 本文档的验证 main 自带 Gprs4G_Init 点火——模块未连接时给一个确定的开机起点；已连接时不动它（§3）。

### 1.1 与原工程的差异（引脚/EXTI 等价；行为修订三处 + 归属调整）

| 差异 | 原工程位置 | 现位置 | 理由 |
|---|---|---|---|
| **复位脉冲改为条件执行**：`GPRS_LINK_STATUS == 0` 才发 500ms 点火脉冲 | boot 4G.c:50-52（无条件脉冲） | 4G.c `Gprs4G_Init` | **热重启保护（zxl gprs_4g.c:57-69 同款实病修复）**：模块由独立供电，MCU 热重启（看门狗复位、OTA 失败重启）时模块可能仍在线、MQTT 会话健在——无条件拉复位会杀掉好会话，之后要等 ~50s 陈旧会话过期才能重连。**对 bootloader 是刚需**：OTA 流程正是「应用置 UPDATE_flag → 重启 → bootloader 点火」，此刻模块大概率连着服务器，boot 版每轮 OTA 白罚 50s。只在 LINKA 为低（模块确实未连接）时才发脉冲，上电冷启动时 PC5 下拉读 0、脉冲照发，行为不变 |

| `gprs_online` 变量**删除**（原 `gprsonlineflag`，上轮曾更名） | boot 4G.c:9 | **删除** | ISR 不再维护标志后无人可写；「是否在线」的信息源就是 PC5 电平本身，宏直读无歧义。GPRS/正式 main 的联网判断改用 `GPRS_LINK_STATUS`（见 §7.1） |
| **复位脉冲后喂狗** | —（boot 无） | 4G.c 脉冲末尾 `WDG_Feed()` | 500ms 阻塞延时占 IWDG 窗口（3.18s 标称/2.12s 最坏）的 ~1/4；zxl 在上电脉冲与运行期复位后均喂狗（gprs_4g.c:68/81）。正式 main 开狗后必需；验证 main 不开狗时为无害寄存器写 |
| `extern u8 gprs_online;` | `USER/main.h:32` | —（随变量删除） | 原归属归位条目作废 |
| `GM4G_Init` → `Gprs4G_Init` | 4G.c:11 | 4G.c | 原缩写 GM 脱离上下文不可读；新名 = GPRS 模块（Gprs）+ 4G 代际 |

## 2. 4G.h（重写，全文）

```c
#ifndef __4G_H
#define __4G_H
#include "sys.h"

/* 4G 模块网络状态输入脚 PC5：模块把「是否已连接服务器」的电平从这根线送进来，
   高 = 已连接、低 = 未连接；同时是 EXTI5 的中断源（双沿触发）。
   实测语义（2026-11-25 4G 阶段定论）：注网成功期间它可以是 0，MQTT 连上服务器才变 1
   ——它是「服务器连接状态」，不是「网络注册状态」。
   宏名 GPRS_LINK_STATUS = GPRS 链路状态；对应模块数据手册的状态引脚 LINKA
   （PC4 的 LINKB 同源，本工程暂只留位不用，引脚名出处保留在注释里）。
   在线判断一律直读本宏（无共享标志变量，不存在竞态面） */
#define GPRS_LINK_STATUS  PCin(5)

/* 4G 模块初始化：状态脚输入 + EXTI 双沿中断 + 条件复位脉冲（仅模块未连接时点火） */
void Gprs4G_Init(void);

#endif
```

## 3. 4G.c（重写，全文）

```c
/* 4G 模块驱动：管两件事——
   ① 模块的网络状态线（PC4/PC5）读入与中断：在线判断一律经 GPRS_LINK_STATUS
      宏直读 PC5 电平，ISR 只清中断标志（zxl 同款：不维护共享标志，无竞态面）；
   ② 模块的复位脉冲（PA1）：仅在 LINKA 为低（模块未连接）时点火——热重启保护，
      MCU 复位不杀模块健在的 MQTT 会话（zxl gprs_4g.c 同款实病修复）。
   串口收发不在本文件——AT/数据通道归 usart2，协议归 GPRS 模块。 */

#include "4G.h"
#include "led.h"        /* LED_LINE（PD13）：在线指示灯，由 main 轮询随动（不在 ISR 里） */
#include "delay.h"      /* delay_ms：复位脉冲的高电平保持时长 */
#include "wdg.h"        /* WDG_Feed：500ms 脉冲延时后喂狗（占 IWDG 窗口 1/4，
                           正式 main 开狗后必需；wdg.h 属 WDG 阶段产物，见文档 §1.1） */

/* 4G 模块初始化：配好两根状态输入脚 + 一根复位输出脚 + EXTI 双沿中断，
   最后按模块实际状态决定是否点火 */
void Gprs4G_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;    /* GPIO 配置块：输入脚与输出脚共用 */
    EXTI_InitTypeDef EXTI_InitStructure;    /* EXTI 配置块：PC5 双沿中断 */
    NVIC_InitTypeDef NVIC_InitStructure;    /* NVIC 配置块：EXTI9_5 中断优先级 */

    /* 三路时钟：GPIOC（PC4/PC5）、GPIOA（PA1）、AFIO（EXTI 引脚复用映射） */
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC | RCC_APB2Periph_GPIOA | RCC_APB2Periph_AFIO, ENABLE);

    /* PC4 = LINKB（模块第二状态脚）：下拉输入，本工程暂只留位不用 */
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_4;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_IPD;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOC, &GPIO_InitStructure);

    /* PC5 = LINKA（网络状态脚）：下拉输入，既是电平读数口（GPRS_LINK_STATUS 宏）也是 EXTI5 中断源 */
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_5;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_IPD;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOC, &GPIO_InitStructure);

    /* PA1 = 4G 模块复位脚：推挽输出，用于给未连接的模块打复位脉冲 */
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_1;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOA, &GPIO_InitStructure);

    /* EXTI5 映射到 PC5：双沿触发——模块上线（上升沿）与掉线（下降沿）都进 ISR；
       ISR 只清标志，状态观察由消费者轮询电平完成 */
    GPIO_EXTILineConfig(GPIO_PortSourceGPIOC, GPIO_PinSource5);
    EXTI_ClearITPendingBit(EXTI_Line5);
    EXTI_InitStructure.EXTI_Line    = EXTI_Line5;
    EXTI_InitStructure.EXTI_Mode    = EXTI_Mode_Interrupt;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Rising_Falling;
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;
    EXTI_Init(&EXTI_InitStructure);

    /* EXTI9_5 中断通道：抢占 2、子优先级 3，不抢系统关键路径 */
    NVIC_InitStructure.NVIC_IRQChannel                   = EXTI9_5_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority        = 3;
    NVIC_InitStructure.NVIC_IRQChannelCmd                = ENABLE;
    NVIC_Init(&NVIC_InitStructure);

    /* 条件点火：先确保复位脚为低、给 10ms 稳定，再看 LINKA——
       模块已连接（PC5=1）则绝不能拉复位，否则杀掉健在的 MQTT 会话，
       重连要等 ~50s 陈旧会话过期（OTA 重启场景每轮都踩）；未连接才点火 */
    GPIO_ResetBits(GPIOA, GPIO_Pin_1);
    delay_ms(10);
    if (GPRS_LINK_STATUS == 0)
    {
        /* 复位脉冲：PA1 拉高 500ms 再放低——给模块一个确定的开机起点 */
        GPIO_SetBits(GPIOA, GPIO_Pin_1);
        delay_ms(500);
        GPIO_ResetBits(GPIOA, GPIO_Pin_1);
        WDG_Feed();     /* 500ms 阻塞延时后喂狗（验证 main 未开狗时为无害寄存器写） */
    }
}

/* EXTI9_5 中断服务：PC5（EXTI5）电平一变就进——只清中断标志。
   在线状态不由 ISR 维护：PC5 电平随时可经 GPRS_LINK_STATUS 直读，
   共享标志（gprsonlineflag）与 ISR 内点灯（LED_LINE）都是多余的竞态面（zxl 同款） */
void EXTI9_5_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line5))
    {
        EXTI_ClearITPendingBit(EXTI_Line5);
    }
}
```

## 4. 验证 main（USART 与 4G 联测，替换 USART 验证 main）

一条真实链路同时覆盖两块内容：**PC → USART1 接收（DMA+IDLE）→ 中断转发 → USART2 发送 →
4G 模块（真实对端）→ 模块应答 → USART2 接收 → 环形缓冲 → main 轮询取出 → printf 回显**，
外加模块点火与在线状态观察。不需要跳线——本板 PA2/PA3 直连 4G 模块座、未引出排针，
跳线回环在硬件上不可行；4G 模块本身就是 USART2 的唯一对端，也正是天然的验证对端。

```c
/* USER/main.c —— USART 与 4G 联测：PC → USART1 → 转发 → USART2 → 4G 模块，
   应答经环形缓冲回显；同时观察模块点火与网络在线状态 */
#include "stm32f10x.h"
#include "sys.h"
#include "delay.h"
#include "usart.h"
#include "led.h"
#include "4G.h"

static u32  blink_cnt = 0;    /* 心跳计数：主循环存活标志，printf 同步输出 */
static char s_rx_buf[128];    /* 模块应答回显缓冲：每轮最多拷 128 字节，超出部分下一轮继续 */

int main(void)
{
    u16 avail;     /* 环形缓冲当前可读字节数 */
    u16 n;         /* 本轮实际拷出并消费的字节数 */
    u8 tx_probe;   /* TX 探针计数：前 20 秒直接发 AT，绕过 USART1 转发，隔离发送方向问题 */

    delay_init();               /* SysTick 时基 */
    NVIC_Configuration();       /* 中断分组 */
    uart1_init(115200);         /* 调试口：printf + PC 命令接收（DMA+IDLE） */
    uart2_init(115200);         /* 4G 口：与模块对通 */
    LED_Init();
    LED_CLOSE();                /* 全灭基准态 */

    tx_probe = 0;           /* 探针清零 */
    printf("4g test start\r\n");
    printf("reset pulse on PA1 (only if module not connected), wait module boot ...\r\n");
    Gprs4G_Init();          /* 电平/EXTI 配置 + 条件复位脉冲：未连接的模块从这里点火 */
    delay_ms(3000);         /* 给模块 3 秒开机时间再进轮询 */

    while (1)
    {
        delay_ms(500);          /* 半秒节拍 */
        LED_ERR = !LED_ERR;     /* 位带翻转 LED_ERR：完整周期约 1 秒，灯光心跳 */
        LED_LINE = (GPRS_LINK_STATUS != 0);   /* PD13 随 PC5 电平随动（原 ISR 职责移入轮询） */
        blink_cnt++;            /* 心跳计数递增 */
        printf("4g alive, cnt=%u, LINK=%d\r\n",
               (unsigned int)blink_cnt, (int)GPRS_LINK_STATUS);

        if (blink_cnt % 4 == 0 && tx_probe < 10)     /* 每 2 秒一次 TX 探针，最多 10 次（覆盖前 20 秒） */
        {
            /* 直接调发送函数：不经过 USART1 转发，单独验证 PA2→模块RX。
               命令用 USR 私有格式：前缀 usr.cn# + AT，裸 AT 不被本模块受理（原工程 gprs_tx.c:84 同款） */
            Usart2_Send((u8 *)"usr.cn#AT\r\n", 11);
            tx_probe++;
            printf("tx probe %u\r\n", (unsigned int)tx_probe);
        }

        avail = Usart2_RxAvailable();          /* 模块应答检查 */
        while (avail > 0)
        {
            n = Usart2_RxCopy(s_rx_buf, sizeof(s_rx_buf));   /* 拷出（不消费） */
            Usart2_RxConsume(n);                             /* 消费 */
            s_rx_buf[n] = '\0';                              /* 补字符串结尾，按文本回显 */
            printf("echo %u bytes: %s\r\n", (unsigned int)n, s_rx_buf);
            avail = Usart2_RxAvailable();                    /* 一帧可能超过 128 字节，取到空为止 */
        }
    }
}
```

每 0.5 秒一条 `4g alive`，报 **PC5 原始电平（LINK）**：状态变化经 EXTI 触发 ISR（只清标志），
真实状态由本轮询直接读电平——下一条打印即可看到；PD13 由轮询随动点亮/熄灭。

**测试方法**：模块启动信息（`RDY`、`+CPIN:` 等 URC）会经环形缓冲陆续回显为 `echo N bytes: ...`；
再从 SSCOM 发一行 `usr.cn#AT`（**两个条件缺一不可**：① 勾「发送新行」——命令以 `\r\n` 结尾才被受理；
② 带 `usr.cn#` 前缀——本模块是 USR 私有 AT 格式，裸 `AT` 不响应，原工程全部命令均以此前缀发送），
应看到 `echo N bytes: OK`（模块应答）。**注意：自己发的命令本来就不会被 echo**——它走的是
USART1→转发的输出方向，不经过环形缓冲；能看到回显的只有模块吐出来的内容。

**TX 探针的判读**（前 20 秒每 2 秒直接向模块发一次 `AT`，绕过 USART1 转发）：

| 现象 | 结论 | 下一步 |
|---|---|---|
| `tx probe N` 后出现 `echo ... OK` | `Usart2_Send` + PA2 + 模块 RX 全通；问题出在 **USART1 转发路径**（DMA/IDLE）或 PC→USART1 | 排查 usart1.c 接收转发，PC 端查发送新行/端口 |
| `tx probe N` 打了 10 条、始终无 `OK` | 发送方向断：`Usart2_Send` 函数 / PA2 接线 / 模块 RX，三选一 | 查 PA2 到模块 RXD 的连线与模块串口配置 |
| 连 `tx probe` 都没打 | 主循环没跑到探针（不太可能，心跳在动就一定会打） | 回报完整串口输出 |

**热重启保护的验证**：模块在线（LINK=1）时按一下板上复位键（只复位 MCU）：复位后串口若
**立刻**恢复 `4g alive` 且无模块重启 URC（无 `RDY` 横幅）、LINK 保持 1，即脉冲被正确跳过、
模块未被打断——这正是 OTA 重启场景要的效果。对照：模块掉线状态（LINK=0）复位，应看到
脉冲执行、模块重新开机（URC 重新出现）。

本板 PA2/PA3 直连模块座、无排针可短接，不存在跳线回退路径——模块不在位时链路无对端，
echo 无输出属预期；USART 部分的验证同样以模块为对端完成。

## 6. 验证清单（USART + 4G 联测，全部通过才算完成）

1. 编译 0 Error；
2. 串口收到 `4g test start` + 条件脉冲提示，随后 `4g alive` 约 0.5 秒一条（LINK 列实时变化）；
3. **echo 链路**：模块启动 URC 陆续回显为 `echo N bytes: ...`；SSCOM 发 `usr.cn#AT`（勾「发送新行」）后收到
   `echo N bytes: OK`——usart1 接收、转发、usart2 收发、DMA、环形缓冲一并闭环；
4. 模块 NETLIGHT 规律闪烁——PA1 复位脉冲生效、模块完成开机（对照：上电前模块若静止不动，脉冲后开始闪即为点火成功）；
5. 插 SIM + 天线：模块注册网络并连上服务器后 LINK=1、PD13 亮（轮询随动）；掉线回落 LINK=0、PD13 灭——**电平直读 + EXTI 链路完整验证**；
6. 无 SIM 的情况：LINK 恒 0 属预期（模块活着但不注册网络，PC5 无跳变、EXTI 未触发）——此时可临时用杜邦线把 PC5 碰一下 3.3V 再放回 GND，观察 LINK 瞬间变 1 再回 0，即强制验证双沿中断；
7. **热重启保护**：模块在线（LINK=1）时按 MCU 复位键——重启后无模块重启 URC、LINK 保持 1（脉冲被跳过，§4 判读）；
8. map 文件确认：`4G.o`、`usart2.o` 已链接，`Gprs4G_Init` / `EXTI9_5_IRQHandler` / `USART2_IRQHandler` 符号存在（`gprs_online` 已删，不应出现）。

## 7. 跨阶段边界（4G）

1. **GPRS（后续入库）**：联网判断一律读 `GPRS_LINK_STATUS` 宏（include `4G.h` 即得；`gprs_online` 变量已删，
   原「WAIT_NET/AT_OK 状态跳转依据」的职责由宏直读承担——语义还更准：LINKA 报的是「已连服务器」）；
   串口层不归 4G，AT 交互走 usart2；
2. **正式 main**：上电调用一次 `Gprs4G_Init()`（配置 + 条件点火 + 挂中断）；在线指示灯与联网判断均轮询
   `GPRS_LINK_STATUS`，`main.h` 里不再有任何 4G 相关 extern；
3. **WDG**：`Gprs4G_Init` 脉冲后调 `WDG_Feed()`（wdg.h，WDG 阶段产物）；正式 main 开狗后 500ms 延时
   占窗口 1/4，此喂狗不可省；验证 main 不开狗时无害；
4. **BOOT**：跳转 A1 前需与 USART IDLE 中断一并关闭 EXTI9_5——向量表切走后中断不能再进（BOOT 文档统一处理）。
